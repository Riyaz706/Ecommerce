# Frontend (React + Vite + Tailwind CSS)

This is a fresh React frontend for your **Web_Ecommerce** project, built with:

- **Vite** for fast dev/build
- **React 18**
- **Tailwind CSS 3**
- **React Router** for client-side routing
- **Headless UI** and **Heroicons** for accessible UI primitives and icons

## Getting started

From the project root:

```bash
cd frontend
npm install
npm run dev
```

Then open `http://localhost:5173/` in your browser.

## Main files

- `index.html` – HTML entry with `#root` container
- `vite.config.js` – Vite + React config
- `tailwind.config.js` & `postcss.config.js` – Tailwind CSS setup
- `src/index.css` – Tailwind directives and global styles
- `src/main.jsx` – React entry point
- `src/App.jsx` – App shell, routing, and example homepage
- `src/components/Layout/Navbar.jsx` – Responsive top navigation bar

You can now start adding pages and components under `src/` using Tailwind utility classes and the installed UI libraries.
